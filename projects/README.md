# Монитор курсов валют

## Описание
Скрипт запрашивает курсы доллара и турецкой лиры с API ЦБ РФ, сравнивает их с заданными порогами и отправляет сводку в Telegram.

Получает JSON от API ЦБ, извлекает нужные валюты с учётом номинала и формирует текстовую сводку.

## Установка и запуск
Установить библиотеку:
```
pip install requests
```
Скопировать файл `config_example.py` в `config.py` и вписать свои токен и chat_id.
Пороги настраиваются в словаре `thresholds` внутри скрипта.

## Технологии
Python, requests, Telegram Bot API, API ЦБ РФ
